# Bradford Council Asset Mapping System

Team project for **Bradford Metropolitan District Council** (Jan – Apr 2025), University of Bradford.

A web application where council staff upload asset data (CSV) and view it on an interactive Google Map, filtered by postcode, department, ward and status. It includes user registration with admin approval, email notifications and role-based access (Admin, Editor, Viewer).

**Tech stack:** Laravel (PHP), Blade, Tailwind CSS, JavaScript, Google Maps API, MySQL/SQLite
